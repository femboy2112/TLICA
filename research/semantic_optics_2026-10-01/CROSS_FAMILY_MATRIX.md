# 1. Why the matrix matters

The same formal skeleton appears repeatedly:

\[
S
\xrightarrow{l}
M\otimes A
\xrightarrow{\mathrm{id}_M\otimes c_\Theta}
M\otimes A'
\xrightarrow{r}
S'.
\]

The domain-specific content changes.

The bidirectional interface shape does not.

This is evidence for **cross-family structural reuse**, not proof that one empirical mechanism causes all families.

---

# 2. Different failure loci

The matrix helps localize failure.

## 2.1 Exposure failure

The task-relevant state is not present in \(A\).

Examples:

- off-camera causal context;
- hidden institution relation;
- missing receipt;
- omitted policy consequence.

Repair candidate:

\[
l
\]

or the interface.

## 2.2 Decoder failure

Evidence is available but reconstructed incorrectly.

Examples:

- wrong cultural basis;
- wrong source attribution;
- missing concept;
- frame mismatch.

Repair candidate:

\[
c_\Theta
\]

or a component of \(\Theta\).

## 2.3 Response-policy failure

The observer reconstructs accurately but acts badly.

Examples:

- accurate manipulator;
- high-fidelity but indifferent actor;
- institution knows the issue but incentives block response.

Repair candidate:

\[
\pi
\]

or field/incentive structure.

## 2.4 Residual/update failure

The response is locally sensible but hidden context makes its consequence different.

Examples:

- policy interacts with hidden institutional dependency;
- cinematic response is recontextualized downstream;
- manager action worsens an unseen queue.

Repair candidate:

\[
r
\]

or residual modeling.

# 3. Same optic, different controller

Hold \(\omega=[M,l,r]\) fixed.

Then vary:

\[
\Theta_1,\Theta_2.
\]

If:

\[
c_{\Theta_1}\neq c_{\Theta_2},
\]

then the same interface produces different closed dynamics.

Best empirical families:

- same movie, different trained audiences;
- same political speech, different voter histories;
- same workplace event, different roles;
- same joke, different genre conventions.

This is the cleanest test of the TLICA fiber.

---

# 4. Same controller, different optic

Hold observer state approximately fixed.

Change the interface:

\[
\omega_1\neq\omega_2.
\]

Examples:

- full speech vs clipped speech;
- wide shot vs close-up;
- direct receipt vs rumor;
- full institutional process vs local output;
- explained action vs unexplained action.

This tests the base optic independently of TLICA decoration.

---

# 5. Crossed design

The strongest finite/human design is a factorial:

\[
\text{interface optic}
\times
\text{observer/controller state}.
\]

Every cell must be present before claiming interaction.

For example:

| | observer basis A | observer basis B |
|---|---|---|
| optic 1 | cell | cell |
| optic 2 | cell | cell |

Then test:

- optic main effect;
- observer-state main effect;
- interaction.

This is exactly the kind of design that can distinguish “all interpretation lives in the receiver” from “all meaning is in the carrier.”

---

# 6. Politics-specific firewall

Political applications are descriptive.

Semantic optics may model:

- how voters receive evidence;
- how candidate cues are decoded;
- how media interfaces alter available evidence;
- how reputational/policy information composes.

It does **not** rank candidates, recommend choices, or equate favorability with truth.

---

# 7. Ethical firewall

Interactive performance and social experiments raise independent constraints.

A structural model of:

\[
\text{configured situation}\to\text{real response}
\]

does not supply ethical permission to deceive, manipulate, humiliate, or expose participants.

Ethics is an additional layer.

---

# 8. Core cross-family conjecture

> **Conjecture CF:** A substantial family of TLICA application phenomena can be represented as differences in the base optic \(\omega\), the observer/controller decoration \(\Theta\), or the feedback closure \(r\), without introducing a new foundation coordinate.

This is falsifiable.

A domain that requires a structure not expressible by any of these loci would force revision.
