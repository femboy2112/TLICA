## Literature acceptance criterion

Before a publication claim of novelty or synthesis:

1. use primary sources wherever possible;
2. normalize concept definitions across source families;
3. separate constructs that only share rhetoric;
4. identify which proposed dissociations already have names;
5. run leave-one-family-out reasoning so one literature does not silently define all rivals;
6. explicitly record cases where the paper is repackaging an established mechanism;
7. preserve genuinely new value only where a discriminating probe differs.

If an established construct already predicts the complete target pattern, the new terminology should be reduced rather than defended for branding reasons.
