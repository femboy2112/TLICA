# research/ — working notes and provenance

This folder holds **working research notes and dossiers**: the raw derivations, syntheses,
and integration notes that feed the application papers. It is **not** the front door to the
archive, and it is not part of the primary reading path.

If you are looking for the theory, start instead at the root [`README.md`](../README.md) —
the whole thing in one pass — or the [`docs/` wiki](../docs/README.md), which has one page
per concept and per application paper. The finished, citable work lives in
[`foundation/`](../foundation/) and [`applications/`](../applications/); the notes here are
kept for provenance and are referenced by the papers they informed.

Notes are dated (`*_YYYY-MM-DD.md`) rather than versioned, and each carries its own status
header — typically author-derived and **UNVERIFIED** as an empirical model.
