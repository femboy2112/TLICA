# TLICA math-general term watchlist -- the registry for the semantic-drift gate.
#
# Each entry names a term TLICA borrows from mathematics or physics and also
# uses in a *specific technical sense*. Because the word already carries an
# off-the-shelf meaning in a math-literate reader's head, every such term must
# be PINNED by a dedicated entry in docs/glossary.md -- one that (a) states the
# TLICA sense and (b) fences the math/physics sense it does NOT mean. Where the
# same word is genuinely used at more than one scope (the "field" ladder:
# reality / your-view-of-reality / choice-space / filter-mechanism), the pin
# must name the scopes and the paper must tag which one it means at each use.
#
# This file IS that list. Add one line when a new borrowed term enters the
# archive; the gate (`make check-terms`) then requires a glossary pin for it.
# Blank lines and lines starting with '#' are ignored. On a term line, a token
# is the case-insensitive word-start stem matched in the prose (so "topolog"
# catches "topology" and "topological"); text after '#' is a curator's note.
#
# See scripts/check_math_terms.py.
